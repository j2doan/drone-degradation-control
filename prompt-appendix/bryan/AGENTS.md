# Independent experiment folder

Read README.md for the question and recorded outcome, then GUIDE.md for local
instructions. Code, configuration, model assets and data belong to this folder.
Do not add imports, path fallbacks, symlinks or file links to a parent directory
or another experiment. Installed Python and simulator packages are dependencies.

Keep saved results, receipts and source snapshots unchanged. Those may contain
historical paths; they are evidence, not sources to execute. Record new runs in
a fresh data subdirectory. Do not claim proposed methods or software checks as
completed experimental results.
